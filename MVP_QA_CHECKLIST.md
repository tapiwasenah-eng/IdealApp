# MVP QA Checklist

Before executing a closed beta launch with real founders, the following critical behaviors, edge cases, and limits must be manually validated.

## Core Zero-to-Value Journey
- [ ] **Sign up flow**: Validate Google SSO and Email/password flows securely provision a Firestore profile.
- [ ] **Onboarding completion**: Ensure Company DNA fields save correctly and populate the context for the first document.
- [ ] **Initial Document Generation**: Validate that AI generation completes a multi-section document without hanging or timing out.

## Workspace & Deep Editor
- [ ] **Inline Editor**: Ensure changes block-by-block persist properly and don't wipe out other sections upon browser refresh.
- [ ] **AI Assistant Chat**: Test chat context awareness (does it know the current section?).
- [ ] **AI "Apply to Section"**:
  - [ ] Valid replacement of existing text with generated HTML.
  - [ ] Test markdown vs. HTML parsing edge cases in TipTap.
  - [ ] Validate behavior when switching sections rapidly while the AI is streaming a response.
- [ ] **Stream Interruptions**: Disconnect Wi-Fi during a streaming `/api/ai/complete` generation. Expected: Graceful error toast, UI unlocks, no corrupted partial state saved permanently.

## Usage Limits & Error Handling
- [ ] **Free Tier Exhaustion**:
  - [ ] Trigger > 10 AI completions rapidly.
  - [ ] Expectation: 429 Error returned from API.
  - [ ] Expectation: UI parses error, displays friendly "Daily limit reached" toast, and shows an Upgrade CTA modal.
- [ ] **Session Expiry**: Delete Firebase ID token manually in DevTools, attempt to save doc or run AI. Expected: Kicked out to `/auth` gracefully.

## Data Room & Sharing
- [ ] **Link Generation**: Create a data room, toggle password protection.
- [ ] **Incognito View**: Open `/r/:roomId` in an incognito window.
  - [ ] If password protected, validate the prompt blocks access.
  - [ ] Ensure the rendered document matches the exact state of the founder's workspace.
- [ ] **Analytics Loop**: After viewing in incognito, verify the founder's dashboard reflects +1 view and tracks the timestamp correctly.

## Investor CRM
- [ ] **Kanban drag-and-drop**: Moving an investor from "Discovered" to "Outreach" persists the state.
- [ ] **Associating links**: Attaching a specific Data Room link to a specific Investor profile works as expected.

## Upgrades & Entitlements
- [ ] **Pricing Page**: Trigger "Upgrade" to Pro.
- [ ] **Entitlement Hydration**: Ensure `authStore` updates the `useBillingStore` immediately.
- [ ] **Limit Lift**: Test that AI limits jump from 10 to 100 instantly without requiring a hard page reload.

## Critical Gaps for MVP Launch (QA Blocking Issues)
- **Data Persistence**: We cannot QA data room analytics or session recovery reliably until the front-end stores (documents, data rooms, CRM) are fully synchronized with Firestore instead of local, ephemeral browser storage.
- **Editor Edge Cases**: The TipTap `SectionEditor` combined with the AI HTML injection sometimes requires manual styling tweaks when dealing with complex nested lists or tables generated by Gemini. This requires specific prompt-tuning QA.
